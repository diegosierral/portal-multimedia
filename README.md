# Portal Multimedia

Un portal web interactivo para la gestión y visualización de archivos multimedia, desarrollado como proyecto escolar.

## Características Principales
- **Sistema de Usuarios:** Registro e inicio de sesión con encriptación de contraseñas.
- **Dashboard Interactivo:** Navegación por módulos usando CSS Grid.
- **Módulo de Música:** Subida y reproducción de archivos de audio.
- **Módulo de Fotos:** Subida y reproducción de archivos de imagen.
- **Módulo de Videos:** Subida y reproducción de archivos de video.

## Tecnologías Utilizadas
- **Frontend:** HTML5, CSS3
- **Backend:** PHP
- **Base de Datos:** MariaDB

## Entorno y Planificación
- **Servidor:** Alojado en una máquina virtual de Azure corriendo Debian 12 con Apache.
- **Gestión:** La planeación y seguimiento del proyecto se desarrolló en Redmine.
